# Banana Pro × Flow Prompt Set Matrix

## Shared visual universe

All images belong to the same original SERTAI poster universe: black obsidian and deep navy base, oxide red as the main accent, acid green only for biological/energy signals, chrome and wet metal reflections, high contrast, controlled cinematic rim light, clean silhouettes, premium fashion-editorial poster finish, realistic material behavior, fine film grain, subtle analog halation, selective sharpness, 9:16 vertical composition, no text and no logos.

The image prompts are written in natural language for Banana Pro. Each prompt ends by excluding readable text, logos and watermarks in the actual generation; a poster title can be added later in a separate design layer. The video prompts use no model-specific flags so they work on the common ground of Omni and Veo Fast in Flow Lab; each has one image reference, one continuous shot, one main action, controlled camera movement and a clear end state.

## File naming standard

Image file name: `ID_subject_banana_pro_9x16.png`  
Video reference: `ID_subject_flow_veo_fast_8s.txt`  
Keep the same ID, the same identity anchor and the same reference image for each character. In video generation, change only one of pose, gaze, a single action or camera movement.
